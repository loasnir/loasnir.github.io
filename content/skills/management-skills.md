# マネジメントスキル詳細

- **メンバー育成**: 1on1 や普段のコミュニケーションを通してメンバーへのティーチング／コーチング、エンジニアリングスキル向上のサポート。
- **開発フロー**: スクラム開発の導入・推進。スクラムマスターとしての対応。
- **チームビルディング**: スキルマップ、目標設定、業務効率化のための環境整備、チームビルディングイベントの企画・運営。
- **採用**: 採用計画の策定・実施、選考フローの設計・運用、採用面接。
- **評価制度**: 組織・プロダクトのフェーズに合わせた技能定義の設計運用と改善。
- **インシデント対応**: 状況把握、対応策の検討、エンジニアへの指示出し、調整。

## キーワード（職種・役割）

エンジニアリングマネジメント / テックリード / スクラムマスター / SRE / **FDE（Forward Deployed Engineer）** / **イネイブリング** / **AI ガバナンス** / 採用・評価制度設計
